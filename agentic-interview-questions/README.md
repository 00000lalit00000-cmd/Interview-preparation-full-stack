## How to Use

Each category folder contains a `README.md` index and numbered question files (`qNN-topic.md`). Every question file follows a consistent format:

1. **Question** — The interview question
2. **Answer** — Detailed answer with subsections
3. **Key Takeaways** — Bullet-point summary
4. **Related Questions** — Links to related questions
5. **References** — External links to papers, blogs, docs
